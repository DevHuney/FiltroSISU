# Filtro SISU

Saiba com exatidão e precisão como tem rodado a lista de espera e as notas de cortes da sua futura universidade.

## Configurações
- Execute o arquivo `update.bat` para instalar/atualizar as dependencias
- Instale o Python ele é obrigatório para a funcionalidade do filtro
    
## USAR

- Execute o arquivo `executar.bat`
- Insira o seu curso, campus e etc
- Atente-se a escrever da maneira exata em que se encontra nos PDFs
  
### Finalização

- Testei com as listas da UFS e obtive sucesso, caso tenha problemas entre em contato comigo pela aba issues.
